# how to install

## claude code

```
/plugin marketplace add jitera/jitera-connect
/plugin install jitera-connect
```

## codex

```
codex plugin marketplace add jitera/jitera-connect
```

## cursor

```
npx @jitera/connect
```

## pilot and staging environments

```
npx @jitera/connect --env=studio-stage
npx @jitera/connect --env=studio-06
```
